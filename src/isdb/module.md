The ISDB module contains collective variables, functions and biases originally developed for Integrative Structural and Dynamical Biology. They are related but not limited to the interpretation and modelling of experimental data in molecular modelling.

Actions that require LibTorch, currently [EMMIVOX](EMMIVOX.md), are provided by the
optional [isdb-pytorch module](module_isdb-pytorch.md). The default ISDB module
does not require LibTorch. Enable or install `isdb-pytorch` separately to use
these actions; its module page describes both source and conda installation.
